# FAQ Chatbot

## Description

A Python-based FAQ Chatbot that answers frequently asked questions using a simple graphical user interface.

## Features

- 🤖 Interactive FAQ chatbot
- 💬 Answers frequently asked questions
- 🖥️ Simple graphical user interface
- 🟢 Ask button
- 🔴 Clear button
- ⌨️ Press Enter to send a question
- 📚 Provides answers about Python, AI, Machine Learning, and more

## Technologies Used

- Python
- Tkinter
- ScrolledText
