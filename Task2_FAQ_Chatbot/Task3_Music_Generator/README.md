# Music Generator

## Description

A simple Python-based music generator that creates a melody using the music21 library.

## Features

- 🎵 Generates a simple melody
- 🎹 Uses musical notes and piano instrument
- ⏱️ Sets the music tempo
- 💾 Saves the generated music as a MIDI file
- 🖥️ Displays the generated notes in the terminal

## Technologies Used

- Python
- music21
